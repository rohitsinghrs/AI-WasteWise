# AI WasteWise — Project Scope

## SDG alignment
- Primary: SDG 12 — Responsible Consumption and Production
- Supporting: SDG 11 — Sustainable Cities and Communities
- Supporting: SDG 13 — Climate Action

## Initial problem
Household waste is often incorrectly segregated because users may not know the waste type,
appropriate bin, or recommended disposal action.

## Proposed solution
Use computer vision / machine learning to classify common waste items and provide a
clear disposal recommendation. A later phase will add an AI assistant for user questions.
